Assistant agent architecture

How POST /assistant/query answers a question: a LangGraph supervisor delegates to four specialist agents. They can only reach data through the API's own business endpoints, and every answer passes an evaluation gate before it is returned. The knowledge-graph path is shown in teal.

Specialists and their tools
